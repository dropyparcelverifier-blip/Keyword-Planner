Why this tool runs slowly
This tool runs slowly on purpose. A full run may take several hours. SERP loads are paced with long, randomised pauses and grouped into small batches with rest periods. This keeps the tool within normal browsing behaviour — there is no CAPTCHA-solving and no bypass. If Google serves a verification check the run pauses and you can solve it manually in your browser, then resume.

Image matching
CLIP threshold + strictness profile + per-keyword SERP cap.
Lower = more candidate matches (text + brand filters catch false positives). Higher = stricter visual match (may miss our product in cross-source thumbs). Defaults: loose 0.68 · normal 0.72 · strict 0.82. Slider value used only when profile = Custom.

Pipeline: URL identity → dHash (near-identical re-encodes) → CLIP cosine (different photo of same product) → multi-signal verification (color palette + product-name text + brand context). Final match decision is the combined score ≥ 55. First run downloads ~150 MB CLIP model from HuggingFace (cached in IndexedDB).
Each keyword gets its own Google search to count how many times the product image appears for that specific query.
