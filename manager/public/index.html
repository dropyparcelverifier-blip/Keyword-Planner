💥 Reset everything (danger zone) deletes ALL batches + keywords + activity + commands
Nukes every batch, every keyword row, every activity-log entry, and every worker command. Worker config (KP URL, token, pacing, etc.) is preserved. Cannot be undone.
🧽 Clean orphan keyword rows —
Orphans are keyword rows whose batch_id no longer has any jobs — typically because a reset ran while workers were still pushing results. They're still viewable/downloadable via the Analytics + Downloads tabs but can safely be cleaned once you've grabbed what you need.
⏸ Quiesce workers click to check
Broadcasts pause to every worker. Each worker finishes its current SKU (5-15 min), pushes results, and stops claiming. Once counts hit zero, it's safe to reset or shut down without creating orphan keyword rows.
💾 Database backups —
SQLite VACUUM INTO snapshots — consistent even while the manager is running. Auto-runs on manager startup + every 24 hours. Keeps the newest 7 backups (older ones auto-pruned). Set BACKUP_KEEP_N=0 env var to disable auto-backup; BACKUP_DIR to change the location.
🧹 Cleanup old data
Retention purge — activity log rows and acknowledged commands older than the cutoff are deleted. Jobs and keyword results are kept.
