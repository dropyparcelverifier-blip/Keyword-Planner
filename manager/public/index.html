One-time step after the script finishes:
  1. Chrome opens automatically → visit chrome://extensions
  2. Toggle Developer mode on (top-right)
  3. Click Load unpacked → pick %LOCALAPPDATA%\AdBrainWorker\extension
  4. That's it — extension auto-arms from bundled config.
✓ From then on, every login auto-launches Chrome with the extension armed. No clicks needed.
🔄 Reinstall / update? Re-running the command above is safe. The installer detects existing files, wipes the old extension/ folder, re-downloads the current version, and rewrites worker-config.json. Then just click ↻ reload on the AdBrain card in chrome://extensions.
